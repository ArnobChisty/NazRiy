# NazRiy Customer Guide

## Shop and order

1. Open **Shop all**, **New arrivals**, or **Women** from the navigation.
2. Search or filter the catalogue, then open a product.
3. Choose an available size and colour, select quantity, and add it to the cart.
4. Open the bag icon, review quantities and delivery cost, then continue to checkout.
5. Sign in or create an account when requested.
6. Enter the recipient and delivery address exactly as they should appear on the order.

## Payment

- **Cash on delivery:** place the order and pay when the parcel is delivered.
- **bKash manual verification:** send the displayed amount to the displayed NazRiy merchant number, then enter only the bKash transaction ID. NazRiy never asks for a bKash PIN or OTP. The payment remains pending until an administrator verifies it.

If a transaction is rejected, verify the ID and submit the correct unused ID. Never reuse one transaction ID for multiple orders.

## Track an order

Open the account menu, choose **Orders**, and open an order to view items, payment status, delivery address, and the confirmed → shipped → delivered timeline.

## Account safety

Use a unique password, sign out on shared devices, and contact NazRiy if an order or payment does not belong to you.
