# NazRiy Final Demonstration Script

Target duration: 8–10 minutes.

1. **Homepage (1 min):** introduce NazRiy branding, database-managed hero, top products, collection, responsive navigation, and accessibility focus states.
2. **Catalogue (1 min):** demonstrate search, new-arrival sorting, clothing filter, active stock states, and product details/gallery.
3. **Cart and authentication (1 min):** add a sized/coloured item, change quantity, sign in, and show protected checkout.
4. **COD order (1 min):** submit address, show server-calculated totals, confirmation, and order history.
5. **bKash order (2 min):** show merchant number, explain that PIN/OTP are never collected, submit a transaction ID, and show pending verification.
6. **Admin (2 min):** show dashboard KPIs, fixed grouped sidebar, product activation/stock, banner/navigation management, order status, and bKash verification.
7. **Engineering evidence (1 min):** show PostgreSQL/Supabase health response, tests/coverage, CI workflow, production checks, backup/restore commands, and documentation.
8. **Close:** state that deployment secrets are environment-managed and identify any production URL or external credential gate.
