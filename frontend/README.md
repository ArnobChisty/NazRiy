# NazRiy — Sprint 1 Home Page

NazRiy is a responsive e-commerce home-page prototype implemented from the approved low-fidelity wireframe. Sprint 1 is limited to the frontend home page.

## Implemented sections

- Responsive header and navigation with logo, search, account, login, and cart controls
- Hero banner with headline, supporting copy, visual treatment, and primary CTA
- Reusable featured-product card grid
- About/brand story section
- Promotional campaign and secondary CTA
- Newsletter/contact section
- Footer with navigation, contact details, social placeholders, and copyright
- Desktop, tablet, and mobile breakpoints

## Project structure

```text
D:\NazRiy\
```

## Run locally

```powershell
cd D:\NazRiy\frontend
npm.cmd install
npm.cmd run dev
```

Open `http://localhost:5173`.
