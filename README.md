# NazRiy Clothing Store System

NazRiy Clothing Store System is an online clothing store project developed for a Software Engineering course.

## Project Overview

The system allows customers to browse clothing products, search products, view product details, add products to cart, and place orders. Administrators can manage products, orders, customers, and dashboard information.

## Technology Stack

- Frontend: React
- Backend: Django REST API
- Database: PostgreSQL
- Authentication: JWT Authentication
- Image Storage: Cloudinary
